# CourseWatch 界面与交互规范

适用：macOS／Windows 桌面界面、本地网页、课程管理及试验性学习功能。更新日期：2026-11-15。

本文以当前组件和样式为依据，采用 Apple Design 中的即时反馈、操作可恢复、系统字体、层级明确和减少动态效果原则。参考 [Apple Human Interface Guidelines](https://developer.apple.com/design/human-interface-guidelines/)。本文描述设计约定，不代表所有平台都已完成实机验收。

## 页面结构

- 左侧栏选择平台、全部任务或个人日程；图标提供名称提示和无障碍名称。
- 顶部工具栏显示当前内容及操作。主要操作保持位置稳定，次要操作收进“更多”，避免增加一排等权按钮。
- 课程、任务类型、完成状态依次筛选。全部课程视图按课程分组；选择一门课后只显示该课程内容。
- 普通设置使用弹出面板；平台设置使用独立窗口。同类表单保持相同布局，不在平台窗口内增加平台切换。
- 主设置按“通用、提醒、手机通知、自动学习、数据”切换；分类导航和底部完成按钮固定，正文独立滚动。切换分类保留表单草稿，窗口重建恢复分类。面板宽 680px，受窗口可用宽度约束；分类按钮最小高度 44px，480px 以下采用不等宽列，保留完整名称。底部显示通用／提醒自动保存状态，保存失败可重试。
- macOS 保留系统关闭、最小化控件。Windows 使用对应外壳控件，采用 Windows 窗口控件样式。
- Windows 主窗口保留 12px 外边距、10px 栏间距和两个独立的 18px 圆角区域；600px 以下外边距和栏间距均为 8px。外边距及栏间隙从原生窗口区域中裁掉，显示桌面；不绘制整窗底板、原生边框或矩形阴影，两栏无外圈描边。正文和工具栏使用不透明背景，侧栏保留页面内磨砂。最小化和关闭按钮各 32×32px、间距为 0。
- Windows 主窗口固定 1060×720，平台窗口固定 660×700，按 DPI 换算；工作区不足时缩小并锁定。设置面板固定 680×600px，受可用范围约束。首次启动和关闭使用独立对话框；“窗口与启动”位于“设置 → 通用”。本轮验证见 [Windows 0.2.30 修订 2](../verification/WINDOWS-0.2.30-R2.md)。
- “设置 → 通用 → 主题”提供跟随系统、浅色、深色，保存到应用设置；通过 WebView2 的首选配色让正文、表单、学习面板和原生菜单使用同一模式。

## 尺寸、文字与间距

| 项目 | 约定与当前取值 |
| --- | --- |
| 字体 | 系统字体优先：`-apple-system`、`BlinkMacSystemFont`、`PingFang SC`、`sans-serif`；支持光学字号 |
| 正文 | 桌面基础字号 16px；说明文字通常 13–14px，保留完整内容 |
| 按钮文字 | 常用操作 15px；不通过全大写、加粗整段或扩大按钮制造层级 |
| 标题 | 内容大标题约 25–32px；当前工具栏标题 21px、窄窗口 18px，行高 1.4、字距 `-0.02em`；小标题使用字重区分 |
| 输入控件 | 公共高度 `--d-control-height: 44px`；课程选择器、模型输入统一 44px |
| 常规按钮 | `.glass-primary`／`.glass-secondary` 最小高度 44px，圆角 10px，内边距约 8px 13px |
| 图标按钮 | 常规 36×36px；窄窗口工具栏按现有响应式规则缩为 32px，不缩小正文操作按钮 |
| 工具栏按钮 | 作为紧凑导航例外，文字按钮最小高度 34px、字号 13px；同排保持一致 |
| 图标与文字 | 按钮用 flex 共同居中，图标禁止被压缩；按组合整体对齐，避免单独给图标加补偿位移 |
| 卡片 | 课程选择、自动学习分组圆角 14px；内边距桌面 20px、窄窗口 16px |
| 控件间距 | 同一行 8–12px；字段组 14–16px；不同功能块用 20–24px 间距或分组容器区分 |

避免将所有字号、边距同时写成一组固定比例。文字变长或系统字号变化时，应允许换行和布局增长。

## 按钮和反馈

| 类型 | 用法 | 示例 |
| --- | --- | --- |
| 主要操作 | 一个区域一个主要提交；使用点缀色实底 | 保存课程选择、保存设置、启动自动学习 |
| 次要操作 | 中性底色、边框；不与提交抢占强调 | 查看课程、添加课程、暂停 |
| 图标操作 | 高频、含义清楚；同时提供 `aria-label` 和提示 | 同步、关闭面板、调整提醒 |
| 可恢复移除 | 直接执行，说明恢复入口；保留个人标记 | 移除课程 → 已移除 → 添加课程 |
| 请求中 | 阻止重复提交，保留内容，反馈具体操作状态 | 正在打开登录窗口、正在停止并关闭浏览器 |
| 失败 | 保留输入，显示原因及下一步；不能伪装成空列表 | 登录已失效，请重新登录 |

- 按下时立即出现反馈，释放时提交动作。不要为显示按压效果增加 debounce 或等待动画结束。
- 公共按钮按压缩放到 `0.97`；不移动邻近元素，不改变布局尺寸。
- 只有正在执行的动作禁用相关控件。展开／关闭动效期间不能锁住整页输入。
- 键盘焦点使用清晰轮廓。新的课程与学习组件采用 3px 轮廓、3px 偏移；已有公共控件沿用公共焦点样式。
- 成功提示写已发生的结果，例如“课程选择已保存”；不写未经验证的兼容、效果和资源占用结论。
- 登录提交期间显示“正在验证并保存登录…”，阻止重复点击。学习通验证成功后直接展示同次响应读取的课程；平台设置中的课程选择固定当前平台，默认不勾选新课程，保存后同步刷新主窗口。
- macOS 完成登录前后将当前设置窗口置前。仍然可见的窗口失焦时只暂停轮询，不替换为静态快照；主动隐藏、关闭、最小化时释放页面，恢复后重建。

## 表单和开关

- 标签放在输入框上方并左对齐；标签、说明、错误属于同一个字段组。
- 同类字段保持等宽、相同高度和标签间距。两列仅用于有关联且在窄窗口可自然堆叠的字段。
- “学习方式”使用独立标题和三列选项容器，标题行高 1.5、与选项间隔 8px，避免 Windows 原生 fieldset 把标题压在底色边缘。课程选择框统一为 44px；工具栏标题与数量按文字基线对齐。页面检查同时断言按钮文字不超出点击区域、三项学习方式等高且顶部对齐。
- 日期和时间用原生日期／时间控件；平台与课程用原生选择框；数值输入设置明确的范围和单位。
- 主要提交放在表单底部的操作区，辅助操作位于同一区域。课程选择弹窗的操作区固定在滚动区外，长列表只滚动正文；平台设置内的课程保存同样固定，普通网页内嵌课程列表限制为 `min(46dvh, 420px)` 并独立滚动。窄窗口可换行或整行显示，不截断按钮文字。
- 学习通试验开关固定为 46×28px，滑块 22×22px，距左上各 3px，开启后向右移动 18px；采用绝对定位，不继承普通按钮的内容居中与边框规则。
- 开关表示功能是否启用，不表示任务是否运行。自动学习开启后仍需单独点击启动，运行状态独立显示。
- 模型地址、模型名称和 Key 放在各平台自动学习区域的“模型与设置”面板，主设置只保留实验开关和说明。请求上限与翻页间隔放入面板内的“运行选项”。Key 不回显。
- “自动填入并提交章节练习”同时在启动区域显示，默认关闭；启动前仅保存该选项，保存失败不能启动；模型及 Key 草稿仍需在模型面板明确保存。模型面板保留同一设置，运行中修改需停止后重启。课程作业仍只生成答案。学习通视频栏目不读取题目或请求模型，视频结束并切换检测栏目后才允许请求；视频内弹题沿用独立处理逻辑。
- 学习通播放启动区和运行区提供“播放时处理章节测试”，沿用复选框、12px 内边距和 10px 圆角。关闭后跳过章节测试，保留未完成状态，视频弹题不受影响。运行中修改等待后台确认；失败恢复原值，已发出提交先核实结果。单独选择“章节检测”不受此播放选项影响。构建 27 检查启动／运行两种状态、1060／390／320px 和浅深主题，记录见[章节提交与后台保活验证](../verification/STUDY-SUBMISSION-BACKGROUND-2026-11-14.md)。
- 答题提示词只要求 `{"answers":["答案"]}`：选择／判断题返回编号，多选返回全部编号，填空和文字题返回内容，不要求解释或操作步骤。本地 Skill 只读取已有摘要作为参考，不在答题响应中生成摘要。
- 自动学习功能保持默认关闭；开启说明、模型设置、运行按钮分别对应不同步骤。界面不能替用户勾选确认。

## 课程状态

| 状态 | 界面与行为 |
| --- | --- |
| 待选择 | 首次登录或发现新课程后展示，默认不勾选；不读取任务、不发送提醒 |
| 已选择 | 勾选后保存；同步该课程，可查看课程内容或移除 |
| 已移除 | 显示在独立区域；停止后续任务读取及提醒，保留已有记录，支持添加 |
| 暂无任务 | 课程依然在课程列表中；空课程不能从任务数量推导为不存在 |
| 同名课程 | 按平台课程／班级 ID 区分；同名时显示课程标识帮助辨认 |

保存课程选择前不假定用户要监控全部课程。课程选择和自动学习分开：已选课程可直接后台打开；未选定课程时使用官方窗口手动进入。后台仍运行浏览器引擎。

首次读取时已经截止的任务不补发截止提醒；选择或重新添加课程时已经截止的任务也不补发。历史记录仍可查看；后续截止延长到未来后可以正常计划提醒。

构建 30：章节目录、视频／章节检测状态及课程查询结果中，只有官网状态明确为 `true` 才显示绿勾；保留“已完成”文字。未知、待识别和未完成不显示勾。统一使用 `--study-complete`：浅色 `#237a3b`，深色 `#70d58b`，图标 14–16px，与文字居中。验证见 [构建 30](../verification/RELEASE-0.2.30.md)。

## 色彩、材质与层级

- 正文、辅助文字、背景、卡片、边框和点缀色使用语义变量：`--d-ink`、`--d-muted`、`--d-surface`、`--d-card`、`--d-border`、`--d-accent`。复用现有主题，不在组件里写另一套主题色。
- 构建 31 起默认点缀色为橙色：浅色 `#ba8150`、深色 `#d7ac82`，沿用现有橙色变量。首次加载及缺少点缀色的旧设置使用橙色；已保存的蓝、紫、绿、橙选择继续保留。浅深主题和内容底色独立于点缀色。桌面与窄窗口验证见[构建 31](../verification/RELEASE-0.2.31.md)。
- “设置 → 通用 → 外观”的主题使用原生选择框，提供跟随系统、浅色、深色，默认跟随系统。修改立即显示并自动保存，失败时保留选择供重新保存。手动模式优先于系统外观；跟随系统时监听系统变化。浅深配色、原生输入及课程完成标记统一采用实际主题；macOS 原生材质同步所选模式。
- 颜色不能作为唯一状态线索。运行状态同时显示文字，课程状态同时有名称及操作。
- 结构层使用较深侧栏；内容使用浅／深色卡片；弹窗通过遮罩、边界和阴影分离。不要在两层浅色半透明材质上连续叠加正文。
- 侧栏磨砂玻璃是用户可关闭的独立选项；关闭后使用不透明底色。
- 深色模式检查正文、说明、输入框、选项菜单、提示及确认弹窗。不要只反转页面背景。
- 高对比偏好下加强边界，减少透明度偏好下使用实底；保留文字和控件的可读性。

## 动效

仅为操作反馈、层级变化或状态变化添加动效。不为任务列表加入持续漂浮、自动轮播或装饰性循环。

| 场景 | 当前实现／新增组件取值 |
| --- | --- |
| 公共按钮 | `transform`、`opacity` 160ms；`--ease-out: cubic-bezier(0.23, 1, 0.32, 1)`；按压缩放 0.97 |
| 新课程／学习按钮按压 | 按下时 80ms `ease-out`，缩放 0.97；释放沿公共反馈恢复 |
| 设置面板进入 | 250ms；从 `translateY(6px) scale(0.98)` 回到当前位置与原尺寸 |
| 设置面板退出 | 160ms；沿进入方向返回，遮罩同步淡出 |
| 弹出菜单 | 沿现有 `.popover-*` 规则处理小幅位移及透明度，不新增夸张回弹 |
| 页面切换 | 淡入淡出约 125ms；不滑动整页任务或重播入场序列 |
| 自动学习开关 | 背景颜色 160ms；滑块 180ms，曲线 `cubic-bezier(.2,.8,.2,1)`，位移 18px |
| 同步指示 | 仅忙碌时使用 1.2s 线性旋转；空闲时停止 |

- 优先动画化 `transform` 和 `opacity`，避免通过宽高、定位和大面积模糊动画引发重复布局或重绘。
- 从当前显示状态开始，允许反向操作；不要等待一次关闭动效结束才响应再次打开。
- 手势内容必须跟随指针。下拉刷新仅响应触屏拖动：位移阻尼 0.65、反馈位移 180px 触发阈值、实际移动至少 320ms，触发后冷却 2 秒；达到后显示“松开刷新”。滚轮和触控板只滚动，桌面通过工具栏刷新。嵌套滚动区及表单／按钮上的手势不触发外层刷新，取消或关闭可用状态时清空手势。不要用固定播放的关键帧替代跟随。
- 若将来增加可拖动抽屉或卡片，再采用可中断、可继承速度的弹簧：默认阻尼比 1.0、响应约 0.3–0.4 秒；有释放动量的交互才考虑较小阻尼。当前普通按钮无需引入物理动画库。
- `prefers-reduced-motion: reduce` 下取消位移、缩放、旋转和开关滑行动画；状态继续直接更新。已有公共样式关闭动画，新组件同样处理。
- `prefers-reduced-transparency: reduce` 和 `prefers-contrast: more` 独立于减少动态效果，不能互相替代。

## 通知

- “手机通知”由桌面与普通网页共用 `NotificationChannels.vue`。字段标签左对齐、间距 8px，控件及按钮最小高度 44px；有关联的字段两列等宽，560px 以下改为一列，底部统一保存／取消。
- 邮件与网页推送分别测试，iCloud 日历只在 macOS 桌面开放授权。授权码不回显；错误保留草稿，成功保存才清空密码输入。刷新同步状态不丢弃草稿。
- 明确区分服务接收、收件到达、手机显示和 iCloud 跨设备同步；电脑关机后的日历提醒单独说明。iPhone／iPad 的主屏幕前提写在订阅页面及桌面设置中。
- 验证覆盖 1060／820／390／320px 的浅深主题、普通网页 320px、手机订阅页 768／390／320px；细节及真实设备缺项见[手机通知验证](../verification/MOBILE-NOTIFICATIONS-2026-11-13.md)。

- 标题和正文标注来源平台；正文包含任务名称、开始和截止时间。时间明确使用北京时间。
- 模拟通知明确标“模拟”；未知时间显示“待确认”，不能补造日期。
- 区分平台提交状态与用户个人完成；区分系统通知投递与应用内通知记录。
- 系统通知区分排队与显示状态；任务时间区分首次发现时间与平台发布时间。

## 验收

2026-11-14 主设置分类、自动提交入口及相关模型面板已用模拟页面检查 1060／820／390／320px 浅深主题、分类键盘操作、底部按钮和保存失败重试；记录见[设置与答题验证](../verification/SETTINGS-ANSWERS-2026-11-14.md)。未用这些结果替代真实课程提交、长期登录或 Windows 原生窗口验收。

1. macOS 桌面主窗口检查 1060×720 和最小窗口约 820×600；平台设置检查 660×700 和最小窗口约 480×520。Windows 固定为 1060×720／660×700，屏幕工作区不足时缩小并锁定；检查系统缩放后客户区、浅深主题、长课程名和底部操作。Windows 设置面板固定 680×600px，按可用范围收缩，切换分类不改变尺寸。本地网页另检查 390px／320px。
2. 检查鼠标按压、键盘 Tab、焦点轮廓、原生选择器，以及减少动态效果和高对比偏好。
3. 课程覆盖首次待选择、保存、按课程查看、移除、重新添加、同名课程和空课程。
4. 自动学习覆盖默认关闭、说明取消、确认前不能开启、无需模型的播放／保留页面、生成答案缺少 Key 时禁用，以及运行／暂停／停止反馈。真实启动必须由用户配置并操作。
5. 截图使用虚构课程和 Key，不记录真实会话。类型检查、编译或模拟页面通过不能替代真实平台结果。
6. 修改共用按钮、表单或面板时，同时检查关联界面；更新本文件的对应取值和验证记录。

- 滑杆轨道 44px、滑块 46px、卡片圆角 26px。拖动期间取消位置过渡；松开后以 220ms `--ease-out` 对齐档位，渐变以 180ms 透明度切换，文字颜色 160ms。减少动态效果时取消上述过渡，没有循环闪烁。方向键逐档切换，Home／End 到首尾，Escape 关闭并返回触发按钮。
- 主界面调整思考强度单独保存，不覆盖未保存的其他配置，从下一次模型请求生效；进行中的请求不会重发。模型与设置面板内的改动仍须点击保存。
- 验证记录见[任务与模型验证](../verification/STUDY-TASKS-MODEL-2026-11-14.md)。


## 构建 25：面板对齐与保活入口

- 移除构建 24 的思考强度控件及请求参数。实时输出区、滚动跟随及纯文本渲染保留。
