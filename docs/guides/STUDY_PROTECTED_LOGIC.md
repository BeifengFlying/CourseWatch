# 受保护的学习逻辑

自 2026-11-13 起，视频选择弹题穷举提交与 U校园每 5 分钟保活纳入受保护的学习逻辑。两项逻辑分别保存在独立模块中，保留“严禁删除”注释，并纳入保护清单和打包前校验。更新范围限于本机打包与安装，不上线。

## 学习通视频选择弹题

实现：`packages/study/src/video-quiz.ts`，入口 `solveVideoQuizzes`；调用：`packages/study/src/worker.ts` 的播放循环。

1. 仅接管官方章节页面中唯一可见、能确认所属视频的弹题。
2. 单选和判断逐个选项尝试，多选尝试非空子集；同一弹层多题使用组合，最多 256 组。
3. 每次写入前检查页面、题目及取消信号，写入后回读实际选中项，再点击当前弹层的提交按钮。
4. 收到本轮新的明确错误反馈后换下一组；正确后点击原生继续按钮，弹层关闭后允许恢复正常播放。
5. 提交后没有明确结果时记为待核实，继续操作也不会重复提交；换题、平台要求回看、验证码、人脸或身份验证、未知控件时暂停。
6. 不调用模型，不把弹题结果当作课程完成。作业、章节测验和考试不由该入口穷举。

构建 20 补充：识别没有外层 `.ans-videoquiz` 的原生 `.tkTopic` 视频弹题；排除父级隐藏的 iframe。普通题目读取跳过视频弹题范围，并在题目分支再次检查刚出现的弹题。唯一播放器、逐次判错、结果不明不重试及所有原保护保持；行为测试及 SHA-256 已同步。U校园浏览器参数在保活参数外增加最小化启动参数，保留 300 秒间隔和取消保护。

## U校园每 5 分钟保活

实现：`packages/study/src/unipus-activity.ts`，入口 `keepUnipusActive`；间隔常量 `UNIPUS_KEEPALIVE_INTERVAL_MS = 5 * 60 * 1000`。

- 播放循环和定时保留页面循环均接入；启动学习页后执行一次，后续每 300 秒执行一次。
- 构建 29 起，后台任务使用无界面浏览器，启动及后续弹窗均不显示原生窗口；不再使用焦点模拟。在官方内容 iframe 内分发鼠标活动事件，禁用后台计时器降速，普通超时提示通过已核对按钮的 DOM click 继续。
- 仅用户“打开运行窗口”指令可以切换为可见浏览器：先暂停并等当前操作退出，保留浏览器会话并重新打开当前官网地址；用户点击继续后转回无界面后台。未保存的网页输入不转移，已尝试提交的记录保留，不重复提交。暂停、失败或身份验证均不自动打开窗口。
- 普通“长时间未操作／是否继续学习”提示只点击其唯一可用的继续／确认按钮；提示出现会及时处理，不等到下个 5 分钟。确认后允许媒体再次正常播放。
- 暂停停止活动并清理保活间隔状态，停止关闭受管浏览器；切换中的停止也关闭新浏览器，定时关闭仍由父进程执行。
- 验证码、人脸、本人或身份验证仍暂停；未知弹窗按钮不自动点击。不构造学时、成绩或完成上报请求。官网可因活动事件产生自身的网络请求，平台认可时长以官网为准。

## 严禁删除与保护方式

两个实现文件头部均有“严禁删除”注释；项目 `AGENTS.md` 同步约定。

- 清单：`packages/study/study-protection.json`。SHA-256 固定视频弹题、U校园保活、U校园窗口实现及对应行为测试，检查 worker、定时循环、测试入口及打包入口的调用。
- 校验器：`scripts/verify-study-protection.mjs`；独立命令 `npm run check:study-protection`。
- `pretest`、服务端编译、macOS 和 Windows 打包均执行校验，避免直接调用打包脚本绕过。
- `tests/study-protection.test.ts` 验证模块删除、内容改动及调用丢失会失败；`tests/study-automation.test.ts` 验证穷举、重复错误反馈、提交不明、取消、验证拦截及 300 秒间隔。

保护用于防止意外删除和静默回退，有源码修改权限者仍可修改校验本身，不能视为不可篡改的访问控制。维护时保留上述行为，修改实现后同步行为测试和清单中的 SHA-256，执行类型检查、完整测试和打包；禁止通过删除或放宽校验使构建通过。
