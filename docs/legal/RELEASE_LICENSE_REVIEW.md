## 分发与验证边界

- macOS 和 Windows 使用同一分发文档复制入口，随包保留标准 LICENSE、中英文项目协议、NOTICE、免责声明、隐私说明、第三方声明及历史 Apache-2.0 文本。
- 所有新安装包不附带浏览器，使用用户独立安装的 Chrome／Edge。历史浏览器许可核查仅适用于曾包含浏览器的旧包。
- 历史安装包及其校验文件在本地独立归档；GitHub 上旧 Releases 附件及旧 Actions 安装包产物另行下架，具体检查记录见[0.2.34 归档及下架记录](../verification/RELEASE-0.2.34.md)。
- `private: true` 只防止意外发布 npm 包，不是版权许可。公开源码、标注来源和声明侵权后删除均不能代替必要授权。
- 四项既有界面依赖缺少随包完整许可文本，仍须按下列未决事项处理。未把本机构建通过视为公开分发权利审计通过。
