## 用途限制

**学习通与 U校园实验功能仅用于技术实现验证与参考，不得用于其他目的。** 本限制涵盖自动播放、翻页、页面保留、保活、题目读取、模型作答、选项穷举及自动提交，不因未配置模型、关闭练习自动提交或软件免费而改变。

不得将实验功能用于实际课程任务代办、获取成绩或学时、出勤证明、代学代刷、作弊、收费部署或其他收费服务。使用者自行用于上述用途或其他超出技术实现验证与参考范围的用途，应依法承担相应后果。

“实验”“技术验证”“参考”不是法律豁免，也不表示已取得学校、教师或平台授权。账号所有权、账号持有人同意、能够正常访问、使用原生控件及勾选软件说明，均不能代替平台对相关自动操作的许可。不能确认法律、学校规定、课程要求及平台条款允许相关操作时，不得在真实课程中运行，应使用本地模拟页面或自行控制的测试环境。测试环境仍须具有相应数据和素材的使用权。

## 实际操作

| 功能 | 实际行为及边界 |
| --- | --- |
| 课程与任务查询 | 在登录会话下读取所选课程、任务及官方进度。账号授权不自动包含采集许可；只读也不当然符合平台条款。 |
| 学习通播放 | 正常速度静音播放可识别媒体、翻阅文档；具备模型配置且相关选项开启时，可进入章节检测生成答案。正常播放可能由官网记录进度。 |
| 学习通视频弹题 | 对可识别的视频单选、判断和多选弹题穷举选项并真实提交，最多 256 组；收到明确错误反馈才换下一组，结果不明不重复提交。**该操作不调用模型，不受练习自动提交或播放时章节测试开关控制。** |
| 章节／单元练习 | 配置模型后可生成答案；另行开启练习自动提交才自动填入并提交。提交可能消耗次数、影响成绩且不可撤销。 |
| 课程作业 | 仅生成答案，由使用者手动填入及提交。手动提交不使超出用途限制的使用获得许可。 |
| U校园保活 | 进入学习页时及之后每 5 分钟在官方内容页模拟鼠标活动；普通超时提示出现时自动点击已识别的继续按钮，不等待下个周期。播放和保留页面模式均适用；无需配置模型。暂停停止保活，停止关闭受管浏览器。 |
| 页面保留与后台 | 学习通页面保留只检查本机页面状态；U校园会执行上述保活。无界面后台仍运行浏览器，并可能产生平台官网请求和记录。关闭主窗口或设置面板不等于停止。 |
| 本机计时 | 读取媒体推进及前台阅读停留，不构造额外学时、成绩或完成上报请求。官网仍可能因播放、活动和点击产生记录；本机计时及官网记录均不能证明本人持续学习。 |
| 验证与考试 | 不处理已识别的考试和测评；验证码、人脸及身份验证交由本人处理。页面识别有局限，未知页面或无法确认的操作会暂停，不能把识别保护当作绝对保证。 |

定时关闭受本机时钟、休眠、进程和系统调度影响，不能保证准时执行。停止无法撤回已提交操作、已发送的数据或已发生的费用。不得把媒体播放结束、弹题通过、本机计时或进度百分比表述为本人已完成学习或已取得有效成绩。

## 模型、搜索与本地文件

题干、选项、开启后的截图及启用本地 Skill 时引用的方法摘要，发送至使用者配置的模型服务商。同一题连续两次有效空答案后，程序自动把题干和选项发送至必应 `cn.bing.com`，提取最多 5 条网页标题、链接和摘要，再请求模型第三次作答；不读取来源网页全文。搜索不附带模型 Key、平台会话、截图或本地 Skill，但接收方仍能处理查询与网络元数据。

第三次仍为空时，程序将题目、模型名称、失败原因、原始回复、搜索结果及用量写入本机 `study-model-logs/`。这些文件不自动上传，不属于脱敏系统日志，退出、关闭功能及卸载不保证清除。已有本地 Skill 也可能持续保留。不得公开上传这些文件或无权提供的题目、课程资料及个人信息；保留及删除方式见隐私说明。

每题最多三次模型作答。重做、失败及测试请求可能收费；次数上限不是金额上限，搜索摘要不保证正确，也不构成内容使用授权。不同意上述数据处理时，不要启动模型作答。
