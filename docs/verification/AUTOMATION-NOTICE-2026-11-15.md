## 修改范围

- 实验功能用途统一为“仅用于技术实现验证与参考，不得用于其他目的”；列明不得用于实际课程任务代办、获取成绩或学时、出勤证明、代学代刷、作弊或收费服务。超出用途范围的后果由使用者依法承担，开发者和其他主体依法应承担及法律不能免除的责任保留。
- 学习通视频弹题真实提交、独立于练习自动提交和播放时章节测试开关；U校园进入学习页及每 5 分钟模拟活动、普通超时出现时自动继续；官网可能形成记录、不证明本人学习。上述说明不能代替平台授权或构成法律豁免。
- 补充模型、必应搜索、第三次空答案持久日志、已有 Skill、确认记录的接收方、保存及清理范围。明确不同意自动搜索时不要启动模型作答，现有实现无独立搜索开关。
- 两平台说明版本分别更新为 `2026-11-15.1`、`2026-11-15.u1`，沿用既有重新确认机制，不清除模型或 Key。有效确认后，在本机数据库按平台和说明版本保存最近时间及确认文字；确认与开启状态在同一事务保存，失败全部回滚。记录不包含身份、IP 或平台授权证明，不自动上传，也不是不可篡改的外部存证。
- 中英文 README 增加 Contributing；贡献说明要求注明第三方来源及许可、确认新增原创贡献的授权范围、保留原许可和受保护逻辑，不转让著作权或预设任意重新许可权。
- 修正第三方声明及隐私说明中旧 Apache-2.0、随包浏览器和数据仅在内存等过时表述。随包文档复制清单纳入自动化边界和贡献说明。
