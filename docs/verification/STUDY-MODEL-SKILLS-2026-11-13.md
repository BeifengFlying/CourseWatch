# 检测、模型设置与本地 Skill

日期：2026-11-13。版本：0.2.0，构建 21。

## 改动

- 主窗口、本地网页和原生菜单栏移除播放按钮圆形实底，使用三角播放／双竖线暂停图标。网页点击区域 64px，原生 56×44px，保留文字或辅助功能名称。
- 未配置模型时，章节／单元练习通过未锁定的官方入口跳过，不写入完成状态；没有入口、人工验证、考试或页面未切换时暂停。
- 播放时自动使用已保存的当前平台模型。自动提交仍需独立开启；未开启只生成答案并暂停供核对，课程作业手动提交。
- 运行中允许编辑并保存模型，当前进程继续使用启动时的配置，停止并重新启动后应用。清除 Key／Skill 需先停止。错误与保存结果放在表单底部。
- 自动暂停／失败／异常退出写入现有通知队列；重复状态去重，手动暂停不触发。系统通知投递受原有开关、系统权限和专注模式影响。
- 本地 Skill 默认关闭，开启时需阅读独立说明、勾选额外 token 费用与数据／错误风险并确认，再保存。服务端拒绝未带确认标记的首次开启。
- Skill 文件位于应用数据目录的 `study-skills/chaoxing.json` 和 `study-skills/unipus.json`，目录权限 0700、文件 0600（Windows 按文件系统权限），临时文件原子替换。仅保存模型生成的方法摘要、关键词、题型、时间及观察次数，不保存原始题干或 Key。最多 40 条，每次最多引用 3 条；方法未经成绩验证，不能执行。
- 总结与答案在同次请求返回，不单独请求总结；输入摘要与输出摘要均可能增加 token 费用，计入模型实际返回用量。关闭后新任务停止读取／生成／更新，已有文件保留，可单独清除。
