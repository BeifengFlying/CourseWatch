# 章节提交、测试开关与后台保活

2026-11-14，Asia/Shanghai。macOS arm64，版本 0.2.0，构建 27。本机打包，不发布线上版本。

## 原因与改动

- 在基础生命科学官网页面只读核对到：每题嵌套 `.singleQuesId`／`.TiMu`，同时包含 `answer题号` 和 `answertype题号`。旧代码按 `answer` 前缀寻找答案，误把题型字段计入，随后以“官网答案字段尚未保存”暂停。改为按题号精确匹配隐藏答案字段。字段重复、选中项不一致、保存值为空或错误仍会停止，不直接写隐藏字段。
- “播放时处理章节测试”默认开启，保留已有播放设置的行为。播放前可关闭；运行中也可单独切换。关闭时取消尚在进行的模型或填写操作，跳过检测栏目，测试不计为完成。已发出提交时先等待结果；结果不明仍暂停，不能以关闭测试绕过核实。单独“章节检测”及视频内弹题不受影响。更改只保存该选项，不覆盖模型及 Key 草稿。
- U校园保留 300 秒间隔、普通超时继续、取消和人工验证保护。改为内容页内的鼠标活动事件和已核对按钮的 DOM click；移除浏览器鼠标移动及输入点击，保活不调用置前窗口。受保护清单及行为测试同步更新。

## 验证

- 类型检查通过；完整测试 46 个文件、293 项通过。
- 自动提交回归使用隔离官网模板结构，覆盖 `answertype`、嵌套题目容器、单选、判断、原生保存及一次提交；原有异步保存、保存失败、延迟确认测试保持通过。
- worker 运行测试验证：即使已配置模型，运行中关闭章节测试后也不请求模型，通过原生栏目继续。API 测试验证后台未确认时不持久化，失败保留原设置。
- `scripts/check-study-test-toggle.mjs` 检查启动选择、运行中切换、失败回退、不重启任务、不覆盖模型及自动提交设置，以及 1060／390／320px 浅深主题布局。
- 原任务／模型界面脚本检查 1060／820／390／320px 浅深主题、直接检测、实时输出及提交选择通过。
- 在本机独立安装的 Chrome 中使用隔离 U校园页面：窗口先最小化，执行首次保活、普通超时继续、模拟 300 秒后的第二次保活和释放，CDP 读取窗口始终为 `minimized`。没有发送真实学时请求。

## 限制

官网读取用于核对字段与处理函数，没有填写、请求模型或提交真实章节测验。隔离页面提交通过不等于真实成绩验证。后台窗口检查不等于 U校园认可学时；Windows 未进行本机运行或安装包验收。
