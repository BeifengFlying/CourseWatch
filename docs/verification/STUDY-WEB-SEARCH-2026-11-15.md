# 空答案第三次联网检索

日期：2026-11-15（北京时间）。本记录对应构建 32 源码；双架构 macOS 安装包检查及发布记录见[构建 32 验证](RELEASE-0.2.32.md)。未替换已安装的应用。构建 31 的原有行为见[空答案重做记录](STUDY-EMPTY-ANSWER-2026-11-14.md)。

## 行为

- 学习通和 U校园共用作答流程。第一次返回完整的空答案 JSON 后，保留原题、图片和参考资料，要求重新作答一次；第二次仍为空时，先联网检索，再发起第三次模型作答。前两次返回有效答案时不搜索。
- 搜索使用必应公开网页结果，将题干及选项作为查询，提取最多 5 条标题、链接和摘要。不读取来源网页全文，不向搜索服务发送模型 Key、平台会话、题目截图或本地参考资料。无需新增搜索 Key。
- 第三次请求保留前两次上下文，将实际搜索摘要作为待分析资料，要求比较题干含义、限定条件及选项文字，选择有资料支持且与原题匹配度最高的答案。网页中的指令不作为操作指令；相似题答案须重新映射到原题选项编号，不照搬字母或搜索排序。
- 第三次无法作答时，要求在同一次响应中返回 `{"answers":[],"reason":"无法作答的具体原因"}`。原因限定为缺少的信息、资料冲突或无法对应选项等实际障碍，不要求输出思考过程，不增加第四次模型请求。有效答案继续使用原有答案格式；未返回有效原因时明确记录“模型未返回原因”。
- 运行日志记录第三次联网作答状态、摘要数量和实际来源链接。模型输出区只展示接口实际返回的内容。
- 第三次空答案先记录原因及原始回复，再暂停任务；运行记录最多展示原始回复的前 24000 字符，完整回复另存于本机数据目录的 `study-model-logs/<时间戳>-<平台>-<唯一标识>.json`。每次失败独立保存，包含题目、模型名称、实际原因、原因是否缺失、检索来源及三次模型用量；不写入请求头、平台会话或请求正文。文件先写临时文件再重命名，macOS 权限为 `0600`，不混入脱敏系统日志。写入失败时明确记录失败状态，保留本轮运行记录并按原空答案原因暂停。
- 第二次重做及第三次联网作答均计入模型请求上限，搜索 HTTP 请求不单独计入模型请求次数。请求上限检查与计数在每次重做开始时执行；搜索失败时保留已计入的第三次请求次数，但不发送第三次模型请求。成功返回时汇总最多三次模型 token 用量。
- 搜索超时、服务拒绝、验证页面或没有可用摘要时暂停，不发起第三次模型请求。第三次仍为空时明确提示并暂停，不发起第四次模型请求。返回有效答案仍须通过原有选项范围、数量及填写前核对。
- 暂停、停止及切换任务的取消信号阻止后续搜索或作答。模型 HTTP 错误、流中断、截断及格式错误不触发联网重做。视频弹题穷举、结果不明不重复提交和 U校园保活保护保持原逻辑。

## 验证

- `npm test`：合并最新 Windows 源码后重新运行，52 个测试文件、335 项测试通过，测试前受保护逻辑校验通过。
- `npm run typecheck`、`npm run build`（网页、扩展与后台）通过。
- 单元测试覆盖第三次检索后成功或仍空、上下文及图片保留、三次用量汇总、搜索凭据隔离、来源解析及去重、响应大小限制、搜索失败、取消、请求上限、流式解析和无效答案拒绝；同时覆盖具体原因、原因缺失或类型无效、原始回复保留、独立日志文件、文件权限及写入失败后仍暂停。
- 隔离页面运行测试确认：第一题第二次作答成功，第二题第三次联网作答仍空；共计 5 次模型请求及 1 次搜索请求，只缓存第一题有效答案，未选择或提交页面选项。暂停前运行记录和本地文件均保留第二题原因、原始回复及检索来源。
- 通过构建后的 `searchStudyQuestion` 实际请求必应，取得网页标题、来源链接及摘要。示例搜索结果含与题目无关的条目；该连通检查不证明检索结果相关性或模型答案正确性。

模型响应及课程页面验证使用模拟数据，未调用真实模型作答或提交真实课程。搜索引擎返回结构、网络访问及摘要覆盖范围可能变化；没有相关依据时仍允许空答案并暂停。
