# 构建 8 精简版验证

日期：2026-11-12。版本 0.2.0，构建 8。目标为 macOS 14 及以上的 Apple Silicon（arm64）和 Intel（x64）。

## 变更范围

- 恢复可选的 `--slim` 构建，不分发浏览器二进制，默认完整构建不变。
- 原生启动器根据包内是否含 `browsers` 目录选择内置浏览器或本机 Chrome／Edge，不继承外部浏览器路径设置。
- 本机浏览器仍使用 CourseWatch 独立资料目录，不读取日常浏览器资料；未安装时提示安装，不自动下载。
- 保留构建 7 的认证、原生令牌和采集边界修复。没有调整界面、平台适配或数据库结构。
- README、隐私说明、第三方许可说明及 DMG 内安装说明列出两版区别；精简包不覆盖已有完整包。

## 检查结果

- `npm run typecheck` 通过；11 个测试文件、82 项测试通过，包括本机 Chrome／Edge 选择、缺失浏览器提示和内置浏览器选择。
- arm64 和 x64 包内 Node／SQLite、API、网页、模拟任务、通知队列、采集子进程检查通过；包含构建 7 的认证边界、原生令牌撤销及监控来源过滤检查。
- 两种架构的包内 Playwright 均调用本机 Chrome，在独立临时资料目录完成有窗口和无头启动、静态页面渲染与关闭检查；未使用真实课程或日常浏览器资料。Intel Node 经 Rosetta 运行，启动的是本机浏览器，不等同于 Intel 浏览器验证。
- 两个应用的临时签名完整性检查、DMG 完整性检查通过。精简包未内置 `browsers` 目录，Node 和 SQLite 为各自目标架构。
- README 头图改用从原图缩小的 256px 图片，随应用与 DMG 保留，避免离线文档图片缺失或重复携带 1024px 源图。图片视觉内容不变。
- 两种架构的精简安装包约 50 MB，准确字节数及 SHA256 以构建 8 Release 附件和对应校验文件为准；保留构建 7 完整包，不以本次精简包覆盖。

## 验证边界

本次使用 Apple Silicon Mac。Intel 的 Node／SQLite 通过 Rosetta 检查，本机浏览器为当前 Mac 上安装的版本，不等同于 Intel Mac 实机浏览器、界面或通知验收。本次不使用真实账号完成平台登录或全量采集，也不重新验收通知授权、长期稳定性与全部界面；既有平台及界面范围见[构建 6](VERIFICATION-BUILD6.md)，认证修复见[构建 7](VERIFICATION-BUILD7.md)。

精简版重新调用系统 Chrome／Edge，可能再次遇到此前的 macOS 应用管理权限提示，不能沿用完整版的短时检查结果宣称该问题已排除。浏览器自动更新后的兼容性尚未长期验证。

两版共用同一个 Bundle ID、应用名称及数据目录，不能并行运行。替换前需退出并备份数据，切换浏览器后可能需要重新登录。应用仍使用本地临时签名，未完成 Apple 公证。
