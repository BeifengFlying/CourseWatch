# 刷新、学习通查询与学习助手显示

日期：2026-11-13。修改的是当前工作区源码及 `dist/web`、`dist/server`；本次未替换 `/Applications/CourseWatch.app`。

## 修改

- 滚轮及触控板不再触发下拉刷新，桌面保留工具栏刷新。触屏下拉需要约 277px 手指位移（0.65 阻尼后达到 180px）及至少 320ms 实际移动。等待松手的时间不计为移动；嵌套列表、输入控件、取消手势不触发；刷新后冷却 2 秒。
- 学习通首页默认不显示课程卡片，先点击官网“课程”导航。封面与标题指向相同地址时合并，按课程及教学班编号匹配，不以名称猜测。目录查询复用列表页，每门课目录页读取后关闭，等待 iframe 数据而非固定延时。
- 增加当前官网 `.catalog_name` 名称结构；隐藏的完成图标不当作完成证据。未知状态仍为待确认。批量超时保留本次已读取结果，其他课程可以单独重试。
- 学习通、U校园实验学习助手在对应开关开启后显示；关闭或取消确认后隐藏。普通课程进度查询独立显示，不要求启用实验功能。网页和桌面界面行为一致。

## 验证

- 类型检查、网页构建和服务构建通过。
- 全量 180 项测试通过；随后新增的两个查询进程生命周期测试单独通过，共覆盖 182 项。新增导航测试覆盖先打开课程页、重复链接、同名不同教学班、延迟目录 iframe、隐藏完成标记及未加载失败；生命周期测试覆盖超时保留部分结果、无结果时报错及进程释放。
- `scripts/check-refresh-study.mjs` 通过：两个开关分别确认开启／关闭、取消前不可提交、平台互不启用、普通网页隐藏实验助手、课程查询保留；桌面 1060／820 和窄屏 390／320px 两主题无横向溢出。滚轮惯性、短促触摸、嵌套列表、取消手势均产生 0 次刷新；持续下拉产生 1 次，冷却期间不重复。
