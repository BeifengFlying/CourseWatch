# 应用更新检查验证

日期：2026-11-15（北京时间）。初次检查对象为元数据 0.2.32 的工作区源码；该阶段未生成安装包。后续合入 0.2.34 最新源码，发布目标为 0.2.35，包内验证另见[0.2.35 验证](RELEASE-0.2.35.md)。旧安装包不会自动获得该功能。

## 行为

- “设置 → 通用 → 应用更新”提供自动检查开关、手动检查、版本状态、更新说明和“查看更新并下载”。普通网页设置提供相同入口。新版本同时在主界面显示提醒。
- 自动检查默认开启，后台启动约 30 秒后尝试，此后间隔至少 24 小时；手动检查间隔至少一分钟。间隔及开关保存在本机数据库，重启不绕过间隔；并发检查合并。关闭课程监控不影响版本检查，关闭自动检查后仍可手动检查。
- 仅请求 `api.github.com/repos/BeifengFlying/CourseWatch/releases?per_page=20` 的公开元数据，禁止重定向，15 秒超时，响应上限 1 MiB；不附带平台会话、模型 Key、GitHub Token 或用户课程数据。
- 识别 `vX.Y.Z` 和 `vX.Y.Z-desktop` 标签，按数字比较主、次、补丁版本，包含公开测试版，忽略草稿及不符合格式的版本。同版本优先桌面发布页。只接受本项目固定 GitHub Release 页面，界面再次校验下载地址。
- 每个新版本只写入一条应用通知，沿用已开启的系统通知路径；不进入邮件或网页推送投递队列。更新后取消相同或更低版本尚未投递的旧提醒，记录保留。关闭系统通知时仍可在应用内查看更新。
- “查看更新并下载”只通过外部浏览器打开对应发布页，不下载、执行安装包或运行远程脚本。使用者自行选择架构、核对来源和校验文件，退出应用并备份数据后安装。
- 更新说明按纯文本展示，最多保存 8000 字符；失败保留上次成功版本及时间并显示错误，不误报为已是最新。退出时中止未完成检查。
- 隐私说明补充 GitHub 接收方、网络元数据、本机缓存与通知记录、开关和清理范围；检查成功不代表安装包安全、签名或第三方许可核查完成。

## 验证结果

- `npm test`：54 个文件、345 项测试通过；测试前受保护逻辑校验为 5 个文件、9 个入口。
- `npm run typecheck`、`npm run build:web`、`npm run build:server`、`npm run build:extension` 通过。
- 使用临时目录执行分发文档复制，确认贡献说明、自动化边界、两份验证记录及截图可随包复制；临时目录已移除。该检查不代表已生成或验收安装包。0.2.35 沿用后续去图规则，仅复制文档并将展示图引用改为在线地址，不复制截图。
- 自动更新单元及接口测试覆盖数字版本比较、桌面标签、公开测试版、草稿与恶意地址拒绝、固定请求及无凭据、日间隔、重启保留、并发合并、自动关闭后手动检查、重复通知不进入手机投递、升级后取消过时提醒、限流／格式错误／空列表／超大响应、保留上次结果及退出取消。接口沿用配对和来源校验，状态读取不联网。
- `node --import tsx scripts/check-app-updates.mjs`：桌面及普通网页 × 1060／390／320px × 浅深主题，共 12 组检查通过，无横向溢出，窄窗口标签保持横向可读。保存失败时开关恢复；关闭自动检查后手动检查仍有效，两界面共享持久状态。
- 界面检查使用一次模拟版本检查，确认仅一条应用通知、零手机投递；更新说明中的 HTML 保持文本，没有执行。点击下载仅捕获到本项目 `v0.2.99-desktop` 模拟发布页地址，没有打开外部页面、下载或安装。
- 共保存 8 张截图，人工检查桌面 320px 深色与网页 1060px 浅色。初次检查发现窄窗口标签竖排及普通网页主按钮颜色缺失，修正后重跑全部 12 组。
- 另行只读请求真实 GitHub API，HTTP 200；同一解析函数识别版本 `0.2.34`、公开测试版标记及地址 `https://github.com/BeifengFlying/CourseWatch/releases/tag/v0.2.34-desktop`。该请求未创建应用通知，也未下载或执行任何产物。
