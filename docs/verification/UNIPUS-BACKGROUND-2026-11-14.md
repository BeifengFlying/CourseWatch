# U校园后台窗口

2026-11-14，Asia/Shanghai。版本 0.2.29，构建 29；本机修复与打包。

## 问题与修改

- 旧实现以有界面模式启动浏览器，靠 `--start-minimized` 和课程打开后的最小化保持后台；未持续约束后续窗口。保活仍启用焦点模拟。问题反馈记录显示运行期间仍有窗口前置；现有诊断日志不足以确定当次由哪一个网站事件触发。
- U校园后台任务改用无界面浏览器，保活、网页 `window.focus()` 和弹窗仍在无界面进程内运行；不再以最小化保证后台，也不再启用焦点模拟。
- 每 300 秒页面内活动、普通超时按钮 DOM click、暂停及身份验证保护保留。不构造平台学时或完成上报。
- “打开运行窗口”先暂停并等当前操作退出，再把登录会话转移到可见浏览器，重新打开当前官方地址；仅该操作触发前台模式。继续后转回无界面模式，关闭可见浏览器。
- 转移保留 cookies、localStorage、IndexedDB 和官方源的 sessionStorage；未保存的网页输入不转移，界面已说明。模型答案和提交尝试记录保留在 worker，未知提交不会因切换重新发出。失败保留原页面，取消或停止不会自动重新启动窗口。
- 受保护实现、窗口实现及测试的 SHA256 同步；保留打包前检查，增加无界面启动和手动切换的入口检查。

## 验证

- 类型检查通过；完整测试 49 个文件、303 项通过。

- 实际 worker 测试验证启动、手动 show、resume 依次请求后台／前台／后台，show 后保持暂停。测试将显式前台请求替换为无界面启动，避免测试打扰桌面；该项覆盖模式切换请求，前台实机显示尚待验证。
