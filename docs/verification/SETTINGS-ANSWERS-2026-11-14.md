# 设置、章节检测与会话验证

日期：2026-11-14（北京时间）。本次修改及测试均在本机完成，未操作真实课程提交。

## 行为

- 主设置分为通用、提醒、手机通知、自动学习、数据。分类和底部操作固定，正文独立滚动；切换保留草稿，窗口重建恢复分类。通用及提醒保存失败时保留输入并提供重试。
- 启动区域提供“自动填入并提交章节练习”，默认关闭。启动前只保存提交选项，保存失败不会启动；不会自动保存模型或 Key 草稿。作业仍由用户手动填写及提交。
- 自定义选项通过官网点击事件选择。等待至多约 2 秒确认异步隐藏答案字段；支持题号属性及外部 name 字段，读取内部选项值。等待后再次核对题目和选中状态，不能确认则不提交，不直接改写隐藏字段。
- 学习通视频栏目不请求模型，即使预加载了题目或视频刚结束。切换检测栏目后才能生成答案；发出模型请求前再次检查。视频弹题仍使用原有独立模块。
- 模型提示词只要求答案 JSON，不要求解释、操作步骤或新 Skill 摘要。已有 Skill 可继续作为参考，模型返回内容仍需通过选项范围和答案数量校验。构建 31 首次返回空答案时要求重新作答，同一题连续两次空答案才暂停，详见[空答案重做验证](STUDY-EMPTY-ANSWER-2026-11-14.md)；后续源码增加第二次仍空时的第三次联网作答，详见[联网检索记录](STUDY-WEB-SEARCH-2026-11-15.md)。
- 课程查询同时读取视频及检测标记。检测附件缺少完成字段时，打开官网卡片只读完成状态；锁定章节不请求，未知及部分失败不推断为完成。目录读取使用禁止媒体播放的查询上下文。
- U校园学习及查询上下文每 60 秒及关闭前保存官网更新的会话。旧任务保存前检查当前令牌，避免覆盖已经更换的登录；凭据文件使用临时文件加密写入后替换，减少读取半份文件的可能。
- U校园后台收到登录失效结果时，已有官方刷新凭据则尝试一次官网门户恢复流程，确认受保护的课程列表接口后重试查询。程序不构造刷新接口或延长令牌有效期。短暂 SSO 回调允许等待，密码输入或身份验证界面仍需用户处理。
