## 原生运行

在隔离的原生 QA 应用中运行同一 Swift 主体代码，测试副本仅替换服务端口、数据目录、应用身份，并添加检查调用。通过 8 项运行断言：后台启动、悬浮处理器打开面板、摘要读取、弹窗尺寸、移开处理器关闭面板、最小化收起、隐藏后释放 WebView、重新打开恢复窗口。悬浮与移开由测试调用处理器验证，未用物理指针逐一验收菜单栏交互。

通过 CUA 在实际 AppKit／WKWebView 窗口读取并检查新版任务中心、平台面板、60px 官网图标与原生窗口控件。左侧使用固定深色外观的 HUD 原生材质，避免浅色桌面下白色文字对比不足，保留 behind-window 背景透色。保留原有 `UNUserNotificationCenter` 投递路径，新增授权状态查询、系统设置入口及通知中的事项 ID 回跳；原生队列及投递确认接口已测试。通知横幅和点击回跳尚未完成实机端到端验收，最终显示取决于用户授权与 macOS 通知／专注模式设置。

## 交付与边界

交付 `dist/CourseWatch-0.2.0-mac-arm64.dmg`、`dist/CourseWatch-0.2.0-mac-x64.dmg` 及 SHA256 文件；本机应用更新到 0.2.0。更新前在 `.cache/` 保存旧版应用与 SQLite 一致性备份，正式数据保留。最终采用完整目录替换；已安装应用通过 `codesign --verify --deep --strict`。更新后对照最新备份检查任务／日程数量以及账号标识、监控列表与个人设置保持一致。

提醒轮次每 15 秒运行一次，原生客户端每 15 秒读取投递队列，因此提醒是约几十秒级的检查粒度。平台扫描不阻塞提醒轮次。电脑关机／休眠时不能即时发送，运行恢复后合并补发。日程保存在本机，不读写 Apple 日历。

真实平台全量采集、全部课程覆盖、长期资源预算、Apple 开发者签名及公证仍沿用原有未验收边界。测试未登录或修改真实平台账号。
