# Windows 构建与验证记录

初始记录日期：2026-11-12；当时目标为 Windows 11 x64。当前目标为 Windows 10+ x64（最低 Windows 10 2004，内部版本 19041）。本文将 Mac 上的检查、云端 Windows 自动检查与实机验收分开记录。

## Windows 10 兼容范围核对（2026-11-14）

- 外壳目标框架为 `net10.0-windows10.0.19041.0`，`SupportedOSPlatformVersion` 为 `10.0.19041.0`；安装器最低版本由 `10.0.22000` 调整为 `10.0.19041`。
- [Node 24 的平台要求](https://github.com/nodejs/node/blob/v24.x/BUILDING.md#platform-list)包含 Windows 10 x64。[.NET 10 的系统支持表](https://github.com/dotnet/core/blob/main/release-notes/10.0/supported-os.md#windows)包含部分 Windows 10 版本；上游维护支持随具体系统版本及生命周期变化，不等同于本项目实测。
- Playwright 的 Windows 平台判断没有 Windows 11 版本门槛；平台浏览器仍使用本机 Chrome／Edge。原生背景材质属性在 Windows 10 不可用，源码保留共享 CSS 背景回退。
- 本次为源码与依赖要求核对，未生成新 Windows 包，未执行 Windows 10／11 实机安装或运行测试。历史安装包不受源码门槛修改影响。

2026-11-14 的 0.2.30 界面、窗口与启动设置检查另见 [Windows 0.2.30 界面检查](WINDOWS-0.2.30-UI.md)。以下记录保留各轮对应的版本与限制，不代表当前源码的完整验收。
