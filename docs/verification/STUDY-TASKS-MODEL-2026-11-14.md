# 小节任务、模型输出与安装包验证

2026-11-14，Asia/Shanghai。本机 macOS arm64 构建 24，不发布线上版本。

## 改动

- 视频、章节检测分别读取官网任务元数据、原生完成标记和检测结果。未打开栏目不猜测为完成；运行时通过原生栏目顺序进入未完成项。小节整体状态独立保留。
- 每节提供检测按钮，启动时进入检测栏目；运行中切换先中止当前操作、暂停媒体并等待原生页面确认。锁定栏目不点击。
- 修正 `.fanyaMarking_left` 通用容器被当作完成证据，补充 `.answerBg`、`.num_option`、`.num_option_dx` 选择控件；只点击官网控件，核对选中标记及已有隐藏答案字段，不直接伪造保存字段。提交确认弹层可延迟出现，明确结果后继续；不明结果不重复提交。
- 请求使用 SSE 流；接收 reasoning_content／reasoning 及答案增量。接口返回普通 JSON 时保留兼容。响应大小、完成原因、答案结构与取消信号继续校验，失败不自动发起第二次收费请求。
- 思考档位为服务默认、低、中、高、最高；分别省略 reasoning_effort 或发送 low／medium／high／xhigh。接口支持情况须由实际服务确认。主界面仅修改强度时不会覆盖模型及其他设置；正在进行的请求不重发，新强度从下一次请求使用。
- 模型输出只保留在当前受认证的运行状态，不写入系统诊断日志。未收到可展示思考内容时说明，不补造过程。
- 主界面使用更宽的学习与输出卡片和较窄的目录；窄屏转为上下排列。推理滑杆普通档位为蓝灰轨道，只有最高档显示蓝紫渐变与静态亮点。拖动无延迟，松开后短过渡，支持键盘、恢复默认及减少动态效果。
- 默认包不带浏览器；Mac 选择 /Applications 或用户 Applications 下的 Chrome／Edge，Windows 检查系统和用户安装位置。独立资料目录保持。macOS DMG 根目录仅包含 CourseWatch.app 与 Applications，许可和文档保留在应用中。

## 验证限制

没有使用用户真实课程进行模型答题、填写、提交或成绩验证；上述浏览器页面和模型响应均为隔离模拟数据。用户日志只含控件数量和错误阶段，不能据此确认所有失败页的 HTML 模板。最高强度和思考内容是否可用取决于实际模型接口。Windows 源码已同步，未在本机生成 Windows 安装包或完成 Windows 实机验收。U校园保活模块及学习通视频弹题模块的受保护行为未改动。
