# 学习设置、章节与 U校园修复

日期：2026-11-14，Asia/Shanghai。macOS arm64 本机构建 23，不发布线上版本。

## 原因与改动

| 问题 | 证据与处理 |
| --- | --- |
| 点击设置外部丢失填写内容 | 遮罩原本直接调用 close，模型组件卸载后清空 Key。编辑表单不再通过遮罩关闭；模型移至平台内的独立 dialog，明确关闭或切换平台保留当前网页内存草稿。Key 不写入 localStorage。 |
| 模型缺少识别反馈 | 旧表单只有字符串输入，没有读取模型列表或连接测试。现在可读取服务商完整模型 ID，保留自定义前缀，并区分认证、地址、额度和非 JSON 响应。完整 /chat/completions 或 /models 地址去掉末尾，其他路径不擅自补写。 |
| 已完成章节仍播放／答题 | 学习循环在播放／答题之后才检查完成状态，同时目录漏识别学习通 icon_yiwanc。现在在处理内容前读取当前节状态，只有唯一当前位置明确完成时才进入下一节；未知、未完成、冲突、隐藏模板均不跳过。 |
| 嵌套列表阻断滚动 | 课程及进度列表使用 overscroll-behavior:contain。普通内嵌列表改为 auto，目录上下边缘继续滚动主窗口。弹窗的背景仍由原生模态隔离。 |
| U校园进入学习前停在登录页 | 本机旧日志显示启动及目录查询停在 sso.unipus.cn。新版门户保存 PORTAL_STATE_PERSISTENT.tokenInfo，课程应用读取同源 __token。仅当官方 jwt Cookie 与保存的 tokenInfo.jwt 一致时恢复同一令牌，不生成、延长令牌或构造登录响应。 |
| U校园最小化不计时 | 官网公开 general-timing/v12 SDK 在 visibilityState=hidden 时停止计时。保活计时改为打开可见窗口，后端同样忽略该模式的最小化请求。原每 300 秒活动、普通超时继续、暂停／停止与人工验证保护保持。 |

- 单元测试另修复路由误判：lesson 包含 sso，旧正则会将学习路径当作登录。现在按真实路由边界判断；这不解释本机观察到的官方 SSO 重定向。

## 界面验证

- 模型与章节脚本覆盖学习通、U校园，1060／820／390／320px 浅深主题，检查横向溢出、固定保存区、说明确认、失败输入保留、关闭重开草稿、目录当前位置／完成状态／锁定项、起点与暂停时切换。章节脚本另验证列表到顶／到底后主窗口跟随滚动。
- 模型表单标题修正通用 header 样式干扰，取消压缩，使用当前主题的实底；课程标签左对齐。内容宽度至少 700px 时两列 1:1，启动与运行卡片均与目录等宽等高、上下对齐；界面脚本检查实际边界。小节保留官网 DOM 父子关系，支持逐级展开／收起和选择，不根据编号猜测层级。
- 原生 AppKit 使用虚构状态检查两种主题、单／双平台菜单栏卡片，检查操作回调、忙碌禁用及控件边界。单平台高度 392px，双平台 590px，宽 390px。

## 实际请求

- 使用本机已保存模型凭据只读查询模型列表，服务商返回 deepseek-flash 与 deepseek-v4-pro，原填写名称有效。使用一道人工构造的简单选择题调用现有答题链路，返回有效选项；服务商报告输入 151 token、输出 60 token。没有发送真实课程题目；此结果不代表所有题型和答案均正确。
- 使用本机已保存 U校园会话，恢复前打开课程应用跳回 SSO 登录；恢复后进入“我的课程／校内课程”和所选教程初始 HTML，但继续加载后仍跳回 sso.unipus.cn/sso/login；官网内容鉴权 /auth/api/user 返回 302，当前保存会话未能完成内容域登录。曾在空壳执行的一次活动不构成计时成功证据。已取消无效的内容域 localStorage 复制；入口等待可见目录或任务内容，并在跳回官方登录时暂停，保留运行窗口供用户正常登录。会话和凭据未写入仓库或截图。
- 未通过修改完成标记、播放位置或直接构造学时上报来验证功能。U校园真实学时仍未验证，需用户在官方内容窗口正常登录后核对官网记录。平台最终认可学时、成绩、所有教材兼容性及长时运行不作成功结论。
