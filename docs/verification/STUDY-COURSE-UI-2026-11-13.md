## 进度范围

- `POST /api/study/progress` 通过已有学习子进程读取最近打开的官方章节。暂停时仍可读取；查询不导航、不播放、不提交、不修改学习记录、不请求模型。
- 显示可识别的课程／章节、已加载目录的逐章状态、媒体播放位置与总时长、文档当前页与总页数，以及读取时间。未知字段保留未知，不计算整门课程完成率；隐藏完成模板不算完成。当前章节优先按 URL 中的章节 ID 定位，避免误取目录第一项。
- 运行浏览器每 5 秒更新快照，可见的学习页面每 3 秒读取状态；手动查询等待新快照，超时／读取失败显示错误。启动或停止过程中查询只返回当前状态。
- 停止后可看到最后一次快照及其读取时间，退出后台后清除。无运行窗口且从未读取时返回 `progress: null`，不伪造 0% 或已完成。
