## 采集

- 使用 CourseWatch 已保存的本机会话进行只读采集，没有输入密码、打开答题操作或提交任务。
- 计算机平台：读取配置课程的 5 项编程作业和 3 项考试。考试卡片没有详情链接，现从官方页面加载的 `exercises.json` 列表响应读取稳定 ID 与名称；等待列表完成后解析，避免网页外壳被当作空列表。
- 人卫：读取 25 项作业、5 项考试。真实列表的 ID 位于 `tr#examStudent_<ID>`；支持仅有 JavaScript 操作按钮、没有普通链接的行，不执行答题按钮。复用账号导航识别登录，隐藏的验证码组件不再导致误报。
- 人卫旧版仅有标准作业列表时，一次性补充标准考试列表；此后用户移除的列表不会在重启时重新加回。首次人卫登录尚无列表时添加两类列表。
- 人卫本次页面每页 30 条，作业共 25 条、考试共 5 条，均在第一页。没有将本次结果推断为所有账号的完整分页支持。
- 两个平台的已观察考试列表均未提供截止时间，显示“时间待确认”；不使用答题时长或考试状态码推算截止时间／提交状态。人卫已完成作业按原站状态进入“已完成”。
- 手动刷新失败返回具体原因，不再统一提示“检查已完成”。
- 后续复查时人卫会话已过期，手动重试仍返回 `auth_required`，提示“会话失效或返回登录页面”；保留之前已采集的 30 项，不将失效会话解释为空列表。继续刷新需要重新登录人卫。前述 25／5 是会话有效时的实际采集结果。
