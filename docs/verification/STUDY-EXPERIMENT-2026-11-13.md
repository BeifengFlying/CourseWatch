## 入口与操作

1. 在学习通平台设置中完成本人账号的官方登录，保存会话。
2. 打开“设置 → 试验性功能 → 学习通自动学习”。功能默认关闭，开启前显示说明与免责声明，勾选确认后才能开启；开启本身不会启动学习任务。
3. 填写并保存 HTTPS API 基础地址、模型名称和 Key。接口采用兼容的 `/chat/completions` 请求，基础地址可以包含服务商要求的 `/v1` 等前缀，不填写完整请求路径。截图默认关闭；开启时需要支持图片的模型。
4. 点击“启动自动学习”，在独立官方浏览器窗口选择课程并打开起始章节。程序处理最近打开的标签页，不会自动选择账号或课程。
5. 在设置中查看答案、解析、运行状态和服务商返回的 Token 用量。暂停后保留官方窗口供手动处理；停止、关闭功能开关或退出软件时关闭运行浏览器。关闭设置面板或主窗口不会停止任务。

## 实现范围

| 内容 | 当前源码行为 | 完成与异常处理 |
| --- | --- | --- |
| 视频、音频 | 对可识别的原生控件按 1 倍速静音播放，不跳进度 | 播放错误或进度停滞时暂停；播放结束不写入任务完成记录 |
| PDF、课件 | 按设定间隔使用已有下一页控件、幻灯片入口或连续滚动，直至末页 | 平台判断是否完成；未知阅读器暂停，不发送伪造的完成请求 |
| 章节测验 | 提取可识别题目，逐题请求模型；校验答案数量及选项，核对题目未变化，填入后回读，再使用原生提交入口 | 必须看到平台提交结果才记录成功；提交结果不明确时暂停且不重复提交 |
| 课程作业 | 生成答案与解析供查看 | 不自动填入或提交 |
| 考试 | 不进入答题处理 | 识别到考试页面即暂停 |
| 章节切换 | 当前页面处理后使用可用的原生栏目入口；平台显示当前章节完成后才尝试下一章 | 不解除锁定；没有可进入的下一章时结束当前运行，课程是否全部完成仍需核对目录 |

模型请求默认每轮最多 30 次，可设 1–200 次；文档间隔默认 3 秒，可设 2–60 秒。异常不自动重试模型请求。可识别单选、多选、判断及普通文本输入控件；未适配编辑器或无法完整识别的题目会暂停；未提供加密字体解码，题型与学校页面覆盖尚不完整。

## 运行与数据

- 自动学习采用独立子进程和临时浏览器上下文，复用已保存的学习通会话；只在运行期间保留浏览器，后台重启不自动恢复学习任务。没有读取日常浏览器资料。
- API Key 单独加密保存，配置读取、界面草稿和任务导出不包含 Key；Key 绑定已保存的基础地址，更换地址需重新输入。模型请求不携带平台 Cookie，不跟随重定向。
- 题干、选项及开启截图时的题目图片发送给使用者配置的服务商；截图可能包含题目旁的信息。答案与运行记录只保留在服务内存中，界面最多展示各 100 条，详情见 [PRIVACY.md](../../PRIVACY.md#学习通自动学习与模型接口)。
- 启动、停止超时和进程断开有回收处理。此处是实现说明，尚未完成真实平台长时间运行及进程树资源测量。
