# Windows 0.2.30 修订 2

日期：2026-11-14。应用版本和原生元数据恢复为 0.2.30，构建号 30；Windows 修订号单独记为 2。旧的 0.2.30 与 0.2.31 产物保留。

## 修改

- 之前只关闭 Mica，网页的整窗底板仍在。本轮取消该底板，并按侧栏与内容区的实际圆角轮廓设置原生窗口区域；外边距及两栏间隙显示桌面，鼠标可穿过间隙操作后方窗口。
- 关闭原生边框、矩形阴影和页面两栏的外圈描边，圆角保留。主窗口保持固定 1060×720，平台窗口固定 660×700，按 DPI 换算；工作区不足时缩小并锁定。
- 增加“设置 → 通用 → 显示模式”：跟随系统、浅色、深色。后端校验并保存选择，WebView2 首选配色同时控制 CSS 媒体查询与原生表单控件。
- 分发文件名增加 `-r2`，应用显示版本仍为 0.2.30，版本与构建号校验不变。

- `npm test`：49 个文件、305 项通过，包含设置模式保存、后台重开保留及 Windows 修订文件名检查。
