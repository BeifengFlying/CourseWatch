# 雨课堂及学习通接入记录

日期：2026-11-13（Asia/Shanghai）。本次已实现适配器并完成下述检查，尚未完成本人账号登录后的课程、任务及截止时间核对。

## 接入范围

| 平台 | 读取内容 | 尚未确认的边界 |
| --- | --- | --- |
| 普通雨课堂 `www.yuketang.cn` | 受保护的用户信息、学生课程列表、各课程活动中的 type 5 测验及 type 19 作业；通过官方近期考试列表的唯一课程／标题匹配标记考试 | 全部课程发现、活动分页的实际服务端语义、已结束考试分类、type 19 提交状态、实际时间字段与会话恢复 |
| 学习通 | 课程列表的两种已知结构，各课程／班级的作业与考试 H5 列表，任务入口页中明确标注的开始／截止时间 | 学校差异、全部课程与分页覆盖、缺少稳定 ID 的其他页面格式、考试时间字段、长期会话恢复 |

普通雨课堂入口使用 `https://www.yuketang.cn/web`，任务回跳至 `/v2/web/studentLog/{classroomId}`。含真实班级 ID 的课程链接仅用于确认入口，不写入代码、fixture 或本文。学校专用域名和长江雨课堂不在本次范围。

新增平台通过左侧“＋”添加；完成官方登录后点击“完成登录”，后台校验受保护接口并保存独立会话，随后开启监控。无需手填列表地址；平台设置保留自动监控开关、底部保存与取消。已有平台的手填列表功能保留。

日常同步使用保存的本机会话进行 HTTP 读取，不启动常驻浏览器。课程采集继续由短期子进程执行，扫描后回收。官方窗口中的登录及验证由用户本人完成。

## 数据处理

- 任务使用平台任务 ID，命名空间包含课程／班级及类型；相同标题不会导致不同 ID 的任务合并。
- 雨课堂不使用课程结束时间补截止时间，不从标题中的“考试”推断任务类型；近期考试接口未能确认的 type 5 活动显示为习题。type 19 的提交状态保留为未知。
- 学习通只请求作业／考试入口页，不执行脚本、不请求答题及修改入口；按明确标签读取时间，考试时长和提交时间不作为截止时间。
- 雨课堂每页请求 100 条活动，最多 20 页；重复响应、分页失败及条目上限均记录原因。学习通已知列表格式尚未验证服务端分页。
- 每轮最多 90 秒、160 次初始读取、90 个课程分区，每分区最多 2000 条任务；到达上限停止，已读条目保留为部分结果。重定向最多跟随五次，每一跳均检查官方域名和只读路径。429 后停止后续请求；登录失效／人工验证不提交本次候选任务。
- 响应结构错误、业务失败、登录 HTML 不当作零任务。仅明确的空数组／空列表文案可标记为空，扫描仍为部分覆盖。
- 未验证真实账号全量覆盖前，扫描不返回完整账号快照。失败及部分扫描不撤回旧任务；新的未知截止或状态不会覆盖此前已知值。
