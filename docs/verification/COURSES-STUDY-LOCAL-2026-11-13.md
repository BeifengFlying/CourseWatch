# 课程管理与自动学习合并更新

日期：2026-11-13（Asia/Shanghai）。目标：macOS arm64 本机安装，0.2.0 build 10；不提交、推送或发布。

## 变化

- 首次登录雨课堂／学习通后先读取课程列表，用户选择后才读取课程任务。课程记录独立于任务，保留空课程，同名课程按平台课程与班级 ID 区分。
- 课程有待选择、已选择、已移除三个状态。移除停止任务读取与提醒，保留任务及个人标记，可重新添加。全部视图按课程分组，支持课程筛选。
- 首次读取时、选择或重新添加课程时已经截止的任务不补发提醒；截止延长到未来后可正常计划提醒。
- 任务、首次同步和重新登录通知标明平台；已有应用内通知补充平台标识。已由系统显示的历史通知不因此撤回。
- 登录页导航超时或重定向中断时保留仍然打开的官方浏览器，提示用户刷新；浏览器已关闭时仍返回失败。未复现主应用崩溃，不能据此断定此前闪退的全部原因。
- 合并当前学习通自动学习源码，默认关闭。入口为设置中的试验性功能；配置、页面执行与限制见[自动学习记录](STUDY-EXPERIMENT-2026-11-13.md)。
- 按 Apple Design 原则调整课程与自动学习组件的分组、对齐、按钮、开关、焦点和按压反馈。[界面与交互规范](../guides/INTERFACE_DESIGN.md)记录尺寸、颜色、动效和验收方法。

## 源码与模拟检查

- `npm run typecheck` 通过；`npm test`：17 个文件、133 项测试通过。新增检查覆盖首次过期、课程选择、移除恢复、跨平台账号隔离、同名／空课程、不请求未选课程任务以及导航失败不关闭窗口。
- 课程界面在 1060、390、320px 浅色及 390px 深色通过选择、保存、移除、重新添加、课程筛选检查，未检测到横向溢出或页面脚本错误。
- 自动学习界面在 1060px 浅色、320px 浅色减少动态效果、390px 深色通过默认关闭、开启说明、确认前禁用、缺少 Key 禁止启动、设置保存、关闭功能检查。使用临时数据库和虚构模型名称，没有调用真实模型。
- 使用已安装软件内的 Node 和 Chromium，在临时独立资料目录打开真实雨课堂官方登录页，确认页面仍打开、平台为雨课堂；之后关闭并回收。不输入凭据，不读取日常浏览器资料。
- 当前已有雨课堂会话已保存，读取到 39 项任务；这不代表全课程与分页已经核对。

## 安装与验证范围

打包与安装结果以本机备份目录内的 `LOCAL-UPDATE.md` 为准。更新前备份安装程序及本机数据，更新后比较任务身份、个人标记、日程、提醒设置与平台账号配置。

本次没有启动真实课程自动学习、自动提交或调用付费模型。真实学习通会话恢复、学校页面、题型、提交结果、平台认可的完成状态与长期资源仍需实际使用验证；模拟页面检查不能替代这些验证。Windows 和 Intel Mac 未作实机检查。
