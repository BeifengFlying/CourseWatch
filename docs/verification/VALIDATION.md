# macOS 0.1.0 验证记录

日期：2026-11-12。环境：Apple Silicon、macOS 15.7.4、Swift 6.1.2、Node 24.22.1。

## 自动检查

- `npm run typecheck` 通过。
- `npm test`：5 个文件、28 项测试通过，覆盖基线、新增／截止变更、未知值、部分快照、缺失待核实、提醒去重／休眠补发／旧提醒撤销、ID 隔离、保守解析与日期、认证来源、模拟清理隔离、子进程退出、原生令牌轮换、原生通知确认隔离、点缀色保存与无效值拒绝。
- `npm run build:mac` 编译 Swift 外壳、Vue 页面及后台，复制生产依赖和浏览器，生成 DMG 与 SHA256。
- `codesign --verify --deep --strict` 通过；签名是本地 ad-hoc，**不代表 Apple 开发者签名或公证**。
- `hdiutil verify` 通过。

## 本机操作

- 原生窗口启动、自动连接后台、对象切换、平台管理、原生应用菜单及设置入口可用。
- 左右独立圆角与透明间隙、左侧磨砂材质、右侧纯色，系统字体与简短标签。
- 左栏从 78 加宽至 104 像素，调整图标、间距及顶部留白。红黄绿使用 AppKit 原生窗口按钮工厂创建，独立承载在 WebKit／后台静态画面上方；实机截图确认三钮可见，点击关闭后窗口重建、绿色缩放及恢复尺寸可用。最小化动作已调用，界面自动化会重新唤起窗口，未单独确认保持最小化时长。
- 内嵌浏览器打开人卫官方登录页成功；取消后浏览器与采集子进程退出。没有输入或保存真实账号凭据。
- 关闭窗口后后台进程及 127.0.0.1:17321 监听保留；从原生应用菜单退出后，应用与其后台均退出。
- 后台挂起实测：原生状态记录为 suspended，AX 树只剩静态 image，实时 HTML／控件已卸载；恢复后重新出现 HTML 与控件。
- 系统通知测试已进入原生待投递队列。当前工具不能代操作 macOS 通知授权窗口，**未确认系统横幅展示**；需用户手动允许后核对。

## 动效与功耗边界

前台内容按 30 毫秒间隔分组进入，总计不超过 280 毫秒；弹窗 240 毫秒进入／180 毫秒退出，菜单 160 毫秒，使用强 ease-out，只改变 opacity／transform。轮询更新不重播。键盘操作直接响应；跟随减少动态效果与降低透明度设置。没有背景循环装饰动画。

隐藏／最小化／转入后台时释放 WKWebView，普通后台窗口仅保留静态画面。隐藏和最小化时连静态画面也不保留；关闭窗口移除全部界面。回前台重建渲染器。Swift 菜单栏与 Node 监控服务仍运行，原生定时器 30 秒、允许系统合并唤醒；采集浏览器只按需启动。

短时采样时自有两个常驻进程 CPU 均显示 0.0%；后台 Node RSS 约 85–97 MiB，Swift 外壳约 78–119 MiB（静态快照会有开销）。这些是单点 RSS／CPU 观察，**不是整机能耗、峰值、24 小时稳定性或 ≤100 MiB 合计预算的达标结论**，也未完整归属 WebKit 系统进程内存。需继续实测。

## 真实采集边界

jsjks／人卫采集器按已观察结构实现，但只覆盖手动配置的列表。未验证真实登录后的全量分页、全部课程、考试及非编程作业，也未验证自然截止变更的完整端到端流程。所有实际结果保守报告为部分采集；模拟实验不能替代真实平台验收。

当前 DMG 只支持 Apple Silicon、macOS 14+；未在 macOS 14 实机、Intel、Windows 验证。无自动更新、登录自启动开关及多账号切换。
