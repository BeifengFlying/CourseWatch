# 模型空答案重做

日期：2026-11-14（北京时间）。

## 行为

- 学习通和 U校园共用模型请求逻辑。收到完整、可解析的 `{"answers":[]}` 后，保留原题、图片和已有参考资料，附加上次答复及重新核对题目的要求，再请求一次。
- 重做返回有效答案后按原流程继续；同一题连续两次返回空答案时暂停，显示“模型连续两次返回空答案，已暂停；未填入或提交”。下一题单独计算次数。
- 重做请求计入本轮请求上限；成功返回时汇总两次请求的 token 用量。达到请求上限时暂停，不额外调用模型。
- 暂停、停止或切换任务产生的取消信号阻止后续重做。HTTP 错误、响应截断、流中断、格式错误及不符合题目范围的答案继续按原错误处理，不因本次修改而自动重试。
- 重做前清空模型输出区上次的内容，运行日志记录“模型首次返回空答案，正在重新作答（第 2 次）”。只有有效答案通过原校验后才返回执行器，保留填写前核对及提交结果待确认时不重复提交的逻辑。
