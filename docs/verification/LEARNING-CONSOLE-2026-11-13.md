## 当前行为

- 独立选课保存成功后关闭面板；平台设置只保留底部一个保存，同时保存监控与课程选择，成功后关闭窗口。失败保留勾选和错误。嵌入式课程列表中的已移除课程可重新勾选，由同一个保存提交，不提前执行添加。
- 同名课程显示课程编号、教学班编号、教程编号等中文标签；`classroom` 表示教学班编号。
- 模型配置放回设置，平台页只显示所选课程、官方进度和运行操作。正常播放、保留页面不需要模型；生成答案要求已保存模型与 Key。自动提交默认关闭，课程作业仅生成答案，考试不处理。
- 可选后台打开和定时关闭。后台仍使用浏览器；课程入口不明确或同名教程无法区分时不猜测。保留页面每 30 秒检查本机页面状态，不向平台发送人工保活、不模拟活动；父进程负责关闭时间，暂停期间也继续计时。
- 学习通官方计数与章节目录、U校园校内课程卡片的教程计数和官网百分比分别读取，未知不推算。目录查询临时启动浏览器，结束后回收。U校园教程目前仍依赖已有书架发现记录；校内卡片与书架 ID 的实际对应尚待本人账号核对。
- 首次打开未登录的平台提示登录，取消后同一标签会话不重复弹出；仍可查看缓存。
- 两个超星 MIT 项目完整原始副本共 284 个文件，原版权和 LICENSE 保留。独立宿主桥加载第二个项目完整 `course_catalog.js`，只调用目录读取；第一个项目尚未接入运行。原文件逐字节校验，接入代码不写入上游目录，见[说明](../../third_party/README.md)。

## U校园 AutoPlayer 参考范围

[uxudjs/UnipusAIAutoPlayer](https://github.com/uxudjs/UnipusAIAutoPlayer/tree/05401fde70e1f4113e3829e963f520a162a748ae)，固定提交 `05401fde70e1f4113e3829e963f520a162a748ae`，根许可 GPL-3.0。只读取 README 和 userscript，没有执行、注入或复制到上游目录。

脚本通过 DOM 目录切换 Unit／Section／任务，分配页面停留倒计时，可选播放视频并展示日志；其中有自动确认和播放器保活行为。选定脚本未发现 fetch、XHR、GM 网络请求、sendBeacon 或 WebSocket 学时心跳实现；PING／PONG 是页面与 iframe 之间的 postMessage。该静态结论不代表浏览器访问页面不会触发官网自己的请求。

本项目独立实现阅读目录识别、正常播放、暂停和定时关闭。每个媒体元素只尝试正常播放一次；官网随后暂停时不反复恢复，用户明确点击继续才允许再尝试。没有移植脚本的自动确认或保活逻辑。

- `node --import tsx scripts/check-learning-console.mjs`：主窗口 1060、820，平台设置 660、480，附加 390／320px；浅／深色。覆盖成功自动关闭、失败保留选择、唯一保存、配置位置、无需 Key 的播放、答案缺少模型禁用、启动参数、首次登录与取消不重复、详细说明确认和横向溢出。全部运行请求拦截为模拟响应，没有真实任务或模型请求。
