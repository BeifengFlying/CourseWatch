# 协议滚动阅读验证

日期：2026-11-16，Asia/Shanghai。目标版本：0.2.37。

## 行为

- 启动协议、两平台实验说明与本地 Skill 确认在正文未到底时禁用同意操作，并提示“请滚动至协议底部后再同意”。
- 正文到达底部后开放同意操作；有确认复选框时仍须主动勾选。取消和退出始终可用，不记录同意。
- 每次打开重置滚动位置及本次阅读状态，不沿用其他协议或上次窗口的状态。正文完整显示、无需滚动时视为读到底。
- 原生启动确认修订为 `2026-11-16.1`，旧修订确认不能沿用。当前修订已明确同意后，普通重启仍复用确认记录。

## macOS

`node scripts/check-first-run-macos.mjs` 从实际 AppKit 源码提取协议实现，使用独立临时偏好设置及测试正文，未读取真实用户数据。检查长正文的初始禁用、半程禁用、到底启用、强制返回同意仍被阅读状态拒绝、重新打开重置，以及短正文无需滚动；同时检查退出、关闭、接受后重启和正文缺失。浅深主题与 460／320pt 正文宽度下，完整正文和底部操作均在布局内。该检查不代表物理触控板硬件验收。

## 网页

`npx tsx scripts/check-agreement-reading.mjs` 使用临时数据库和虚构课程，覆盖学习通／U校园、1060／820／390／320px、浅深主题，共 16 组。检查实验说明及本地 Skill：未读到底时勾选无效、到底但未勾选仍禁用、取消后重开复位、短正文可直接勾选、按钮可达与无横向溢出。执行 16 次键盘、30 次滚轮和 2 次 Chromium 模拟触控滚动；未启动学习任务、未调用模型或登录真实平台。

截图位于 [agreement-reading-2026-11-16](https://github.com/BeifengFlying/CourseWatch/tree/v0.2.37/docs/screenshots/agreement-reading-2026-11-16)。模拟触控事件不代表真实触屏硬件验收。

## Windows 源码

同步原生协议滚动检查、提示、确认修订与布局检查用例。本轮未在 Windows 编译、打包或运行，不将 macOS 及网页结果视为 Windows 原生验证。
