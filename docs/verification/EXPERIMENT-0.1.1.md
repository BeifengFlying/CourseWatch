# macOS 0.1.1 实验说明

> 历史版本记录。本文的精简包、系统浏览器及旧界面操作不代表当前 0.2.0 构建 6 的行为；当前安装与测试以 [README](../../README.md)、[构建 6 记录](VERIFICATION-BUILD6.md)及[测试版说明](../../DISCLAIMER.md)为准。

## 开始

1. Apple Silicon 选择 `dist/CourseWatch-0.1.1-mac-arm64.dmg`；Intel 选择 `dist/CourseWatch-0.1.1-mac-x64.dmg`。拖入 Applications，启动 CourseWatch。两个版本均需要 macOS 14 及以上。
2. 应用内嵌 Node 与对应架构的数据库模块，无需终端配对。精简包需要本机已安装 Chrome 或 Edge，使用独立资料目录；缺少浏览器时会提示安装，不自动下载。可选内置浏览器版本由 `--bundle-browser` 构建。此包仅临时签名，未做 Apple 公证。
3. 左侧选择平台，右侧管理登录和监控列表。系统通知默认关闭，可在设置中测试后启用。

如果此前运行过源码 CLI 后台，先 `npm run stop`。应用不会接管或终止其他进程；端口冲突或后台退出会显示启动错误。

## 本地集成验证

设置 → 展开“本地实验”：

| 操作         | 结果                                                   |
| ------------ | ------------------------------------------------------ |
| 基线         | 2 项 `[模拟]` 任务及基线摘要                           |
| 再次基线     | 不重复创建任务或通知                                   |
| 新增         | 3 项任务，新增通知                                     |
| 截止变化     | 编程作业截止由 20 小时后变为 36 小时后，历史记录前后值 |
| 失败         | 保留旧任务                                             |
| 空快照       | 保留旧任务并标记待核实，不自动撤回                     |
| 清除模拟任务 | 仅清除模拟账号数据，可重新实验                         |

模拟数据明确标记，不证明真实平台采集成功。也可 `npm run experiment`，使用临时数据库并自动清理。

## 真实平台

精简版使用与旧内置浏览器不同的独立资料目录，升级后首次使用需重新登录。

1. 左侧选择 jsjks／人卫 → 管理 → 登录。本人在独立官方浏览器中输入账号、密码并处理验证码。
2. 进入登录后的教学班或任务列表，复制本人需要监控的**列表页地址**。再回到应用点击“完成登录”，保存会话并关闭独立浏览器。首版要求可确认的退出／注销及任务导航，否则会提示无法确认登录。
3. 填课程名、任务类型、列表页地址，点击添加。jsjks 为本人教学班内实际列表；人卫已观察到作业入口 `https://tk.ipmph.com/exam/a/exam/examTask`。
4. 点击检查，对照官方页面核查条数、标题、截止和来源状态。开启平台开关后默认每 15 分钟检查；认证失效／人工验证会暂停该平台自动采集。
5. 自然发生新任务或截止变化后，核对通知和变化记录。不要通过提交平台作业制造测试。

人卫以独立 HTTP 上下文复用 Cookie；jsjks 按需启动浏览器读取，结束后关闭。浏览器与解析库在短期子进程中运行，登录完成／取消或检查结束后回收。

**当前限制：** 仅识别已配置页面的已知链接和表格，不自动发现全部课程、不自动翻页；人卫考试、jsjks 非编程作业／实验／考试结构未验收。没有稳定 ID 的行跳过并记录问题。前端渲染、DOM 变更、sessionStorage 认证都可能导致失败。所有实际列表均按部分采集报告，不能把零条结果当作无作业。

未知字段不覆盖可信旧值，失败保留缓存，缺失只标记待核实。jsjks“提交中／已截止”是开放阶段，不冒充提交状态；开始时间不冒充发布时间。

## 窗口与后台

- 左右两块有独立圆角、10 像素透明间隙，仍属于一个原生窗口，系统窗口按钮保持有效。左侧原生磨砂玻璃，右侧纯色；设置中可选择并保存蓝／紫／绿／橙点缀色。
- 前台按组进入，平台切换、弹窗和菜单有短过渡；定时刷新不重播。减少动态效果时使用更轻的反馈，键盘操作即时响应。
- 转入后台、隐藏、最小化后，保留静态画面并销毁 WebView；回到前台恢复平台、筛选和未保存表单。关闭窗口也销毁渲染界面。
- 后台只保留菜单栏和监控服务；原生状态轮询 30 秒且允许系统合并定时器。采集和截止提醒仍正常调度，系统休眠期间不能采集。
- 菜单栏：打开、立即检查、暂停／继续、退出。`⌘,` 设置，`⌘W` 关闭窗口，`⌘H` 隐藏，`⌘Q` 退出。退出会停止自有后台。

## 通知与数据

通知记录始终保留；系统通知默认关闭。设置 → 测试通知触发 macOS 授权，首次授权需本人在系统提示中选择。系统接受投递不等于横幅已展示，请核对通知中心及勿扰设置。后台引擎与原生通知轮询各为最多约 30 秒粒度，系统休眠另计。

提交／已批阅／个人完成停止截止提醒；错过多个提醒窗口时合并一条。个人完成不修改平台。截止变化会取消旧提醒。关闭系统通知时旧记录不会积压后重放。

数据目录：`~/Library/Application Support/CourseWatch/`。任务导出使用原生保存对话框，备份保存到数据目录且不含会话。每平台暂支持一个本地账号，不支持自动识别切换账号；不要直接复用不同账号的 profile。

会话快照 AES-GCM 加密、密钥存入当前用户 Keychain。独立 profile 有用户访问权限限制，但不承诺整体加密。不读取日常 Chrome profile、不导出会话，不打印 Cookie 或平台原始响应。

本版尚未完成 24 小时稳定性、整机功耗和资源预算验收。已提供 Intel 与 Apple Silicon 安装包，Intel 后台在 Rosetta 下通过集成检查，仍需 Intel 实机验收。无 Windows 安装包、自动更新、登录自启动开关、多账号和完整课程日历。
