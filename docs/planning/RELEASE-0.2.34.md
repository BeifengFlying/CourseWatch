# 0.2.34 计划

状态：已实现首次打开弹窗，版本更新为 0.2.34。打包与发布结果见[验证记录](../verification/RELEASE-0.2.34.md)。0.2.34 中的 34 是补丁版本，不再对外附加构建号。

## 首次打开：用户协议与免费声明

适用范围：macOS、Windows 桌面应用。首次打开且尚无确认记录时显示弹窗，明确展示用户协议入口、软件免费声明与项目源码地址。

弹窗标题：**用户协议与免费声明**。

弹窗内容须包含：

> 本软件完全免费。
>
> 项目源码地址：https://github.com/BeifengFlying/CourseWatch
>
> 如果你是在其他付费渠道获取此软件，请立即退款并举报该商家。
>
> 使用前请阅读《用户协议》，确认同意后继续使用。

- 《用户协议》链接到随包的 [TERMS.md](../../TERMS.md)，保留完整文本阅读入口；不能只展示摘要或要求到应用包内部查找。
- 免费声明及退款举报提示在弹窗中直接可见，不折叠到协议全文或仅放在 README。项目地址支持点击打开。
- 提供“同意并继续”和“退出软件”操作；不自动确认。确认结果在本机持久化，正常重启不重复弹出；未确认或退出不写入已同意状态。
- 项目地址标为“项目源码地址”；展示源码不改变当前许可中的非商业限制及第三方许可。

## 实现验收

- 两个系统均检查全新用户资料、已有资料但无确认记录、已确认后重启，以及退出后重新启动。
- 检查用户协议全文入口、项目地址、确认状态保存，以及退出软件时的实际进程状态。
- 桌面及窄窗口检查完整文案、阅读顺序、滚动、按钮可达性及浅深主题，按[界面与交互规范](../guides/INTERFACE_DESIGN.md)记录结果。
- 实现、验证及打包分别记录；本计划不代表功能已完成或 0.2.34 已发布。
