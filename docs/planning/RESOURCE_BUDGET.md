# 轻量运行要求与资源验收

运行要求：桌面应用长期运行时应保持低资源开销。该要求优先于此前对 Electron 宿主的候选讨论。本文保留调研阶段的设计与暂定预算，不表示当前程序已达标。当前实现、后台行为与测量边界见[资源占用说明](../guides/RESOURCE_USAGE.md)。

## 1. 首版取舍

- 使用独立 Node 后台，首版不采用常驻 Electron 或 Chromium 界面。
- 管理界面沿用扩展，用户打开才渲染；后台不运行隐藏 Dashboard、日历或持续倒计时页面。
- jsjks 与人卫优先验证可复用正常授权会话的 HTTP 采集。后台浏览器只用于登录或确有必要的短期读取，完成后关闭，不按平台各常驻一个浏览器。
- 托盘、凭据与通知使用必要的系统能力；辅助程序采用短期调用或轻量桥接，其资源开销计入完整进程统计与预算。
- 不引入 Python/Java 服务、Redis、常驻通知桥或本地 AI 模型。其他开源项目移植采集与解析逻辑，不同时运行其完整应用。

Node 仍有运行时开销，后台监控也必然需要资源。验收追求低占用和稳定上限，不承诺零内存、零 CPU 或零耗电。

## 2. 暂定预算

| 场景 | 目标 | 统计边界 |
| --- | --- | --- |
| 空闲后台 | 常驻内存合计不超过 100 MiB | 后台及长期辅助进程，界面已关闭、无登录窗口，不排除自有托盘进程 |
| 空闲后台 CPU | 连续 10 分钟平均不超过单核 0.5% | 使用所有自有进程累计 CPU 时间 / 墙钟时间归一；记录是否有扫描或维护任务 |
| 常规监控周期 | 1 小时平均 CPU 不超过单核 1% | 默认 15 分钟间隔、两个首批平台，包含实际 HTTP 扫描；登录与浏览器采集另列 |
| 浏览器空闲状态 | 无 CourseWatch 管理的浏览器残留进程 | 用户自己打开的 Chrome/Edge 不属于后台受管进程 |
| 连续 24 小时 | 空闲内存无持续上升、进程和句柄数量有界 | 对比预热后及每轮扫描后的稳定值，报告趋势、峰值与回落情况 |

表中数值为实现前的优化目标，尚未在真实平台和两系统上测量。首次基线使用两个平台账号、总计约 10 个教学班、500 个本地任务的可复现实验规模；真实规模不同时明确记录，测试结论仅适用于记录的账号与数据规模。

macOS 记录 RSS，Windows 记录工作集，并另外报告 Windows 私有内存。所有测量注明统计范围、方法与进程树；操作系统缓存、共享页计量不同，不能直接用单个任务管理器截图证明两系统表现相同。扫描和登录的瞬时峰值、结束后回落时间单独报告，不能只展示空闲数字。

若超过预算，先定位并优化，不静默放宽目标；平台确实要求常驻浏览器时，记录为产品约束冲突并给出待讨论的受限方案，不自动启用高占用保活。

## 3. 调度与数据约束

1. 使用持久化到期计划加一次性定时唤醒，避免毫秒级循环；UI 倒计时在打开界面时计算。
2. 两平台默认错峰每 15 分钟检查，限制全局并发、请求体大小、单轮执行时间及重试次数。同账号不重叠扫描。
3. 网络失败退避，登录失效或人工验证时暂停该平台，不循环打开登录窗口。
4. 先同步任务列表，对新增、变化或尚未确认的条目再取详情；完成任务的历史详情避免每轮全量重取，但不能因此漏掉需监测的时间变更。
5. 数据库查询分页并建立必要索引，限制读取批量；限制 HTML、账号任务历史与响应数据的内存保留范围及时间。
6. 日志使用滚动文件和容量上限，默认不记录原始响应；历史与备份有保留策略，清理任务在低频维护窗口执行。具体默认容量在基线试验后锁定。
7. 睡眠期间暂停，唤醒后错峰补查，不阻止系统休眠；通知和计时器不以持续占用 CPU 为代价。

## 4. 浏览器生命周期

同一时间最多一个受管登录/采集浏览器。人工登录不使用自动强制短超时，用户可以完成正常验证并主动取消；取消、成功或可识别失败后释放上下文与子进程。自动采集设置有界超时，超时后先正常关闭，再清理本应用创建的残留进程，不能误杀用户浏览器。

必须实测浏览器关闭后 HTTP 会话仍可读取平台任务。如果只有保持浏览器运行才能维持会话，应单独记录对独立监控与常驻占用目标的影响。会话失效时通知用户重新登录，优先采用可解释的受限状态。

## 5. 测试与报告

在 macOS 与 Windows 11 分别记录：干净启动、数据库预热、空闲 10 分钟、默认频率监控 1 小时、24 小时持续运行，以及重新登录、断网、验证码、长响应、休眠恢复和大量历史任务。

报告至少列出测试版本、系统/架构、Node 与浏览器版本、账号/班级/任务数量、采样间隔、全进程内存/CPU、峰值、句柄/文件描述符、请求次数、浏览器启动与回收次数。区分本地模拟基线与真实平台观测，性能用例通过不能代替任务准确性验收。

如果扫描峰值或电量影响明显，需要调整采集方式、详情缓存或调度策略并重新验证。发布说明只能填写实际测得的结果。
